# Memory · Decisions & Open Questions

> v8 · 2026-10-07 · 각진 형태·박스 선 과다 피드백 반영
> 현재 명세: `ITSDEV-design-v8.md` · 동작 시안: `ITSDEV-Fieldnotes-Preview.html`
> 사용자 확인과 디자인 제안, 시안 검수와 운영 반영을 구분한다.

## Context Snapshot · 현재 유효 범위

성하(aerofleet), 1인 운영. 사용자 확인에 따라 기재된 서브도메인은 **이미 서비스 중**이다. 구축 대상은 **itsdev.kr 콘텐츠 포털 하나**다. 기존 서비스는 소개·승인된 공개 링크로 연결하며 API·인증·DB·서버·배포를 재설계하지 않는다.

사용자는 배포 대상으로 **Cloudflare Workers**를 선택했다. 현재 포털의 기본안은 Astro 정적 빌드 + Workers Static Assets다. 이전 Nginx·OCI·Tunnel·loopback 포트·Micro 자원 검토는 이 포털의 현행 전제가 아니다. 다른 서비스의 운영 정보로 참고할 수 있어도 포털 과제로 끌어오지 않는다.

디자인은 Cobalt·Redline·네 개의 도판과 읽기 흐름을 유지하며, D-019에 따라 외곽 프레임·반복 구분선·각진 컨트롤을 제거했다. 문서 정보와 개정은 선 없는 지면 위에 정렬한다. 이번 작업은 명세와 독립 HTML 시안 수정이며 Astro 앱 구현이나 실제 배포가 아니다.

## H-001 · 2026-10-07 · 포털 배포 대상을 Workers로 정정

- 상태: **사용자 결정 / 문서·시안 반영 / 배포 실행 전**.
- 결정: itsdev.kr만 Astro 정적 빌드 + Cloudflare Workers Static Assets로 제공한다. 요구가 생기면 포털 범위의 동적 기능을 별도로 판단한다.
- 적용: 시안의 기술 설명·대표 글·설계 도판에서 OCI/Nginx/Tunnel 전제를 제거했다. 기존 서비스의 DNS·라우트·보안·배포는 이 결정의 대상이 아니다.
- 인계: 실제 구현에서 Workers 프로젝트·저장소·Custom Domain·배포 권한·404·캐시·버전 복구를 포털 단위로 확인한다.
- ID 설명: 첨부 memory에서 D-015는 디자인 결정이다. 다른 문서 판본에서 같은 번호가 다른 결정에 쓰였을 가능성이 있으므로 이번 배포 정정은 H-001로 식별하고, 첨부의 D-015 이력을 변경하지 않는다.

## D-019 · 2026-10-07 · 디자인 v8: 선을 줄이고 여백으로 구분

- 상태: **사용자 피드백 / 명세·동작 시안 반영 / 운영 반영 전**.
- 입력: “너무 각지고 박스 라인들이 너무 많아서 복잡하다.”
- 결정: 헤더·히어로 타일·캡션·대표 기록·판단 요약·서비스·기술 목록·기록 원칙·주제 목록·접힌 글·표제란의 바깥 테두리와 반복 구분선을 제거한다. 관계는 제목·열 정렬·간격으로 표현한다.
- 형태: 이미지 22px/모바일 16px, 대표 도판·펼친 글·문의 면 20~26px, 주요 버튼·테마·분류는 pill. 그림자나 장식을 추가해 빈자리를 채우지 않는다.
- 히어로: 타일 회전·축선·문장 밑줄을 없앤다. 네 도판은 반듯하게 놓고 캡션은 그림 아래 평문으로 표시한다. 개념도도 외곽 프레임과 노드 윤곽선을 줄인다.
- 읽기: 표제란의 문서번호·검증 상태·REV는 그대로 남긴다. `<dl>`의 의미는 유지하고 칸막이만 없앤다. 개정 표는 머리 아래 가로선 하나를 남기고 최신 REV만 색으로 강조한다.
- 접근성: 기본 장식 선을 줄여도 키보드 포커스와 forced-colors의 식별 윤곽선은 유지한다. native details·필터·테마·모션·JS off 읽기 기능을 보존한다.
- 검증: 로컬 Chromium 133에서 1440/768/390/320px, light/dark, JS off, 필터·글 펼치기·앵커·테마·모션 정지·세션 진입·키보드 skip link 확인. 가로 넘침·누락 앵커·중복 ID·JS 오류 없음. 홈·본문·모바일·다크 캡처 검수.
- 범위: itsdev.kr만 대상, Workers 배포 선택 유지. 기존 운영 서브도메인 변경 없음.
- 산출물: `ITSDEV-design-v8.md`, `ITSDEV-Fieldnotes-Preview.html`, `ITSDEV-design-preview.png`.
- 대체: D-018의 배치·콘텐츠 모델은 유지하되 박스·각진 형태·도판 회전 표현은 이번 결정으로 대체한다. D-015의 ‘표제란’은 데이터와 편집 구조이며 외곽선 강제 규칙이 아니다.
- 재검토: 실제 콘텐츠에서 구역 식별이 어려우면 제목·간격·정렬을 먼저 조정한다. 모든 구역에 테두리를 다시 둘러 해결하지 않는다.

## D-018 · 2026-10-07 · 디자인 v7: 운영 도판과 근거·개정의 읽기 흐름

- 이력 상태: v7 제안·시안 구현. 구조·콘텐츠 모델 유지, 현행 형태는 D-019로 대체.
- 결정: v5.1과 v6의 중복 명세를 v7 하나로 통합한다. 왼쪽 3행 대표 문장, 오른쪽 2×2 설계 도판, 큰 대표 기록, 비율이 다른 기록 갤러리, 비대칭 서비스 소개를 채택한다.
- 시그니처: 표제란과 Revision table을 유지한다. 대표 기록에서 문제·선택·검증을 먼저 보여주고, 네 개의 샘플 글에서 본문·환경/검증 상태·개정 표현을 확인하게 한다.
- 모바일: 모자이크의 기울기·교차 높이를 제거하고 기록은 썸네일+제목의 세로 목록으로 바꾼다. 타일과 큰 문장을 겹치지 않는다.
- 모션: 세션 첫 진입의 10px 상승, 0.8초 치수선, 첫 화면 아래 패널의 1회 진입만 사용한다. 상단 정지 버튼과 OS reduced-motion 우선 처리를 제공한다. blur·clip·opacity로 본문을 숨기지 않는다.
- 데이터: `documentId`는 불변·고유 값, REV는 명시적 `revisions[]`에서 읽는다. slug 해시나 changeSummary 개수로 상태를 재생성하지 않는다.
- 진실성: 네 도판·글·REV·날짜는 샘플로 표시한다. 서비스 개념 도판은 실제 캡처로 표시하지 않는다. 임의 성과·서비스 상태·연락처·API 독점 주장을 넣지 않는다.
- 이유: 기존 16칸 히어로는 큰 문장과 경쟁하고 터치에서 캡션을 읽기 어렵다. 도판을 네 주제로 압축하면 이미지의 밀도를 유지하면서 탐색과 기록의 주제가 일치한다. 대표 글과 표제란은 브랜드 문장을 읽기 기능으로 만든다.
- 대안: 16칸 유지·무한 기술 ticker·모든 콘텐츠 reveal·모바일 가로 갤러리 — 검토 후 채택하지 않았다. 시각 리듬은 크기·비율·높이 차이로 만든다.
- 검증 증거: 로컬 Chromium 133 headless, 1440/768/390/320px, light/dark, JS off, 필터·앵커·글 펼치기·테마·모션 조작. 페이지 가로 넘침·JS 오류·누락 앵커 없음. 화면 캡처 검수. 실기기·다른 브라우저·프로덕션 지표는 미측정.
- 산출물: `ITSDEV-design-v7.md`, `ITSDEV-Fieldnotes-Preview.html`, `ITSDEV-design-preview.png`.
- 인계: T-201A/B 홈과 아티클 구조, T-204 콘텐츠 메타데이터, T-207 폰트·자산 예산, T-208 접근성·브라우저 검수, T-401/402 실제 글·서비스 소개 자료.
- 재검토: 실제 제목·커버에서 읽기 밀도 저하, 폰트 첫 화면 전송 >120KB, LCP 게이트 실패, 모바일 reflow 문제, 사용자 브랜드 방향 수정 시 레이아웃·서체·자산을 다시 판단한다.

## D-014 · 2026-10-07 · itsdev.kr 단일 포털 범위 확정

- 상태: 사용자 범위 정정 / 유지.
- architecture는 포털의 구성·요청·배포·보안·캐시·관측·복구만 기술한다. 서브도메인별 구성표·노드·포트·API·인증·DB·배포 계획은 제외한다.
- 기존 서비스는 운영 중이다. 포털에는 승인된 Public 소개와 외부 링크만 제공한다. 미출시라고 추정하지 않는다.
- T-301~T-306과 기존 서비스의 CORS/Access/API/화면·수집 agent migration은 포털 과제가 아니다.
- 도메인·배포 변경은 itsdev.kr에 한정한다. zone 전체 purge, includeSubDomains/preload, 다른 hostname 라우트를 새 요구사항으로 만들지 않는다.
- D-010/D-011의 기존 서비스 재설계안, D-012의 기존 시스템 변경, D-006의 서브도메인 광고는 별도 운영 범위다.
- 과거의 포털 hostname/vhost/배포 경로 규칙 중 Nginx·Tunnel에 종속된 부분은 H-001로 대체한다.

## D-015 · 2026-10-07 · 디자인 v5: 도면 소재와 의미 있는 색

- 이력 상태: 제안 / 과거 design v5와 Study 04 반영. 현행은 D-018의 구조와 D-019의 형태.
- 유지: 중성 제도지, Cobalt 이동, Redline 개정·정정, Pretendard 자체 호스팅, 표제란과 개정 표.
- 이유: “근거를 남긴다”를 문서의 환경·검증·변경 기록으로 보여준다.
- 대체: 행 기반 홈은 v7 도판·갤러리 구성으로 발전했다. 모션 1개 제한은 D-018의 짧은 진입과 사용자 정지 제어로 대체했다.
- 폰트 위험과 120KB 예산은 유지한다. 시안 subset은 91,468 bytes이며 운영 전체 한글과 fallback 이동량은 구현에서 다시 측정한다.
- 과거의 “모든 대비 검증 완료”는 실제 렌더링·브라우저 접근성 검수 완료를 뜻하지 않는다.

## D-016 · 2026-10-07 · 진입·스크롤 모션 채택

- 이력 상태: 제안 / 과거 v5.1 시안 반영. 현행은 D-018의 구조와 D-019의 형태.
- 유지: 외부 모션 라이브러리 없이 CSS + IntersectionObserver, OS reduced-motion, 아티클 본문 연출 제외.
- 대체: 요소 숨김 후 표시, scroll-driven 퇴장, blur·clip reveal, 긴 진입 시퀀스는 적용하지 않는다. 기본 콘텐츠는 항상 보이고 동작은 짧은 변형으로만 추가한다.
- 참고 사이트 직접 분석이 차단되었다는 이전 기록을 보존한다. 이번 작업에서도 해당 사이트의 기술 스택을 새로 검증하지 않았다.

## D-017 · 2026-10-07 · 참고 구성과 썸네일 도입

- 이력 상태: 제안 / 과거 design §12와 Artifact v2 반영. 현행은 D-018의 구조와 D-019의 형태.

- 실제 이미지가 없는 경우 개념 도판을 사용하고 캡처로 오인되지 않게 표시한다. 검증·상태·성과는 자료가 있을 때만 반영한다.

## 변경 기록 원칙

`ID / 날짜 / 상태(제안·문서 반영·시안 구현·운영 반영·폐기) / 결정 / 이유 / 대안 / 영향 / 검증 증거 / 재검토 조건`.

문서번호와 ADR ID는 의미를 바꾸며 재사용하지 않는다. 사용자 범위·배포 결정은 현행으로 명시하고 이전 판단은 이력으로 보존한다. 포털 링크·배포·캐시·광고 변경은 해당 기록을 갱신한다. 기존 서비스 기능·인증·운영 변경은 별도 프로젝트로 다룬다.
